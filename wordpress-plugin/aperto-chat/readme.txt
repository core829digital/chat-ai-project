Aggiunge l'assistente Aperto a tutte le pagine del sito.

== Description ==

Aperto risponde ai visitatori del sito con le informazioni della tua attività
e raccoglie i contatti di chi vuole essere richiamato.

Il plugin si limita a inserire lo script dell'assistente prima di </body>.
Tutte le risposte e le impostazioni si gestiscono dalla dashboard di Aperto.

== Installation ==

1. Plugin → Aggiungi nuovo → Carica plugin, scegli il file .zip e attivalo.
2. Apri Impostazioni → Aperto.
3. Incolla il codice dell'assistente (inizia con wdg_) e salva.

== Privacy ==

Il widget non usa cookie di profilazione. I messaggi dei visitatori vengono inviati
ai server di Aperto in Unione Europea per generare la risposta.
